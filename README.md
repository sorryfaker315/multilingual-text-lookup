# 多语种文言查库

多语种文言查库是一款在浏览器中使用的 Excel 词库查询工具。可以按文言或 LID 查询，对照 18 个语种的译文，编辑参考格式，并复制单条译文或整行 54 列。

当前工具版本为 **网页版 2.8**。词库版本由使用者导入的 Excel 决定。历次变更见[更新日志](CHANGELOG.md)。

## 快速开始

1. 打开项目的 GitHub Pages 网页。建议使用新版 Chrome 或 Edge。
2. 点击「导入本机词库」，选择自己有权使用的 `.xlsx` 文件。文件应包含 `Master DB` 工作表，首行应有 `Standard LID`、`UX LID`、`Component` 和工具支持的 54 个语言列。
3. 输入简中、韩文、美式英语文言或 LID，按 **Enter** 搜索。也可以点击首页的「试搜」示例。
4. 点击结果查看原文和参考格式。需要调整译文时可直接编辑，离开输入框后保存。

## 搜索与复制

- **搜索**。可自动识别语种，也可在下拉菜单限定简中、韩文或美式英语。工具优先查 ID 和规范化一致的文言，未命中时最多显示 5 条相关候选，并高亮差异。用双引号包住文言可限定为完整匹配。
- **快捷键**。按 **Ctrl+F** 聚焦搜索框并全选查询，输入新文言后按 **Enter** 搜索。**Ctrl+A** 默认全选查询，在参考格式编辑框内则全选当前译文。
- **复制**。单条「复制」和「复制整行 · 54 列」都使用当前参考格式，包括已编辑的内容。整行内容可从飞书目标行的韩文格（`values-ko`）开始粘贴。

## 本机词库与修改记录

- **再次打开**。同一浏览器配置打开同一网站时，会恢复上次使用的词库。拿到新版 Excel 后点「导入新版词库」，也可以通过「本机词库」切回已保存的旧版。
- **查看和恢复**。「本机修改记录」默认展开，列表最多显示两张卡片，其余可在列表内滚动查看。点击卡片可打开对应文言。记录显示 ID、语种、时间和修改前后的值。可以恢复该语种最近一次修改前的值，恢复操作也会留下记录。
- **清除历史**。各版本合计保留最近 50 条修改记录。「清除修改记录」清除当前词库版本的历史，已编辑的译文仍可使用。「撤销上次清除」可恢复最近一次清除的记录，仍受 50 条上限约束。

## 数据与隐私

正式词库由使用者自行提供。Excel 解析、查询和编辑均在浏览器中完成。解析后的词库、参考格式修改和历史记录保存在当前浏览器的 IndexedDB 中。原始 Excel 保留在本机，页面编辑仅更新浏览器里的参考格式。

本机数据不在使用者之间同步。换设备、换浏览器配置或清除本站数据后，需要重新导入词库。请勿在公开仓库、Issue、Pull Request、附件或截图中提交正式词库、内嵌词库的离线版或真实文言内容。反馈问题时请用虚构数据复现。
