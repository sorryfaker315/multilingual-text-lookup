# 多语种文言查库

一个面向本地 Excel 词库的多语种文言查库工具。支持按文言或 LID
查询、对照译文、编辑参考格式，以及单条和 54 列整行复制。

## 当前状态

公开网页版正在准备中。发布后，在线入口会更新在这里。

## 网页版使用流程

1. 打开网页，点击「导入词库」，选择自己有权使用的 `.xlsx` 文件。
2. 导入成功后，输入文言或 LID，按 Enter 搜索。
3. 选择检索结果，查看译文。可以先编辑「参考格式」，再复制单条或整行。
4. 收到新版词库后，点击「更换词库」并选择新版 Excel。

首版计划支持含 `Master DB` 工作表和受支持列结构的 Excel。
具体兼容格式以发布版说明为准。

## 词库与隐私

公开仓库只分发工具代码和可公开的示例。正式词库由使用者自行提供。
网页版的设计是让文件读取、索引和查询都在浏览器内完成。

请勿在 Issues、Pull Requests、附件或截图中提交真实词库内容。
反馈导入问题时，请使用虚构数据复现。

## 版本

工具版本和词库版本分别记录。词库更新由使用者重新导入 Excel 完成。
